# 示例源稿：演示「首列重复写 -> 自动合并」

把本文件复制走改成你自己的内容，然后：

```bash
python scripts/md2mcmod.py 示例-源.md -o 示例.mcmod.html
python scripts/rowspan.py 示例.mcmod.html
```

## 性格事件明细

下表按性格列出四类事件。

| 性格 | 事件 | 触发条件 | 效果 |
| --- | --- | --- | --- |
| 贪吃 | 日常·好 | 当日内进食累计 ≥ 10 次 | 情绪 +4、亲近 +3 |
| 贪吃 | 日常·坏 | 跨日结算：整个游戏日 0 次进食 | 情绪 −3、怨恨 +3 |
| 贪吃 | 特殊事件·好 | 晨起【情绪 ≥ 60】 | 面包×8 |
| 贪吃 | 特殊事件·坏 | 【情绪 ≤ 30】 | 16 格内容器食物减半 |
| 素食 | 日常·好 | 主人吃完植物类食物时在 5 格内 | 情绪 +3、亲近 +2 |
| 素食 | 日常·坏 | 主人 8 格内击杀被动动物 | 情绪 −4、怨恨 +2 |
